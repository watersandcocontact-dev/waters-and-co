# Video/Podcast Repurposing — Service Scope & Workflow

Take a client's long-form video or podcast episode and turn it into
short-form social content. Fully remote, no regulatory complexity.

## Standard deliverable per episode (adjust package by tier)

- 5-10 short vertical clips (30-90 sec) with captions burned in, sourced
  from the strongest moments in the episode
- Auto-generated + cleaned-up captions/transcript
- 1-2 thumbnail options per clip
- Show notes / episode summary (for podcast hosting platforms/YouTube
  description)
- Optional: a longer (3-5 min) "best of" cut for LinkedIn/YouTube

## Workflow checklist

- [ ] Intake: confirm episode file/link, target platforms (TikTok, Reels,
      Shorts, LinkedIn), brand guidelines (fonts/colors/caption style) if any
- [ ] Watch/skim full episode, mark 8-15 candidate moments (hooks, punchy
      quotes, useful tips, emotional moments)
- [ ] Cut and caption the strongest 5-10 into short clips
- [ ] Generate show notes/summary
- [ ] Deliver via shared folder link with a brief note on which clips are
      strongest and why (clients value the judgment call, not just the cuts)
- [ ] Ask for feedback on the first 1-2 episodes to calibrate taste/style
      before settling into a repeatable process for that client

## Tools (no signup required to start — pick what you already have)

- Editing: whatever you're comfortable in (CapCut, Premiere, DaVinci
  Resolve — all have free tiers sufficient for this)
- Captions: most editing tools now auto-generate captions; always
  human-review before delivering, auto-captions get names/jargon wrong
