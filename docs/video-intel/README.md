# Video Intel — reusable knowledge base

Structured breakdowns of strategy/marketing videos, captured 2026-08-08 at the
Owner's request. Built so the lessons can be applied to **any** project — Waters
& Co or future ventures.

## Layout

- `transcripts/` — cleaned, timestamped raw transcripts (source: YouTube caption
  tracks; NoteGPT was login-gated past ~5 min so captions were pulled directly).
- `structured/` — one project-agnostic breakdown per video: thesis, frameworks,
  step-by-step playbooks, tools, metrics, action checklist.
- `waters-co-implementation-plan.md` — the plan of attack applying all seven
  videos to Waters & Co specifically.
