# Land Valuation Objection Letter — Reusable Template

**IMPORTANT — read before using with a real client:** This is a drafting template
only. It is not legal advice, and in every state the actual objection must be
lodged by the property owner (or their authorised agent, which typically requires
a signed authorization/power of attorney form specific to that state's authority)
through that state's official process — usually an online portal or an official
form, not a posted letter alone. Use this to prepare the *content and evidence
argument*; check `state_XXX.md` in this folder for the actual lodging mechanism
per state before submitting anything. Flag to the client where their own
signature or an identity-verified login (e.g. myGov-linked state revenue portal)
is required — you cannot complete that step for them.

---

## Structure

**1. Header / identification**
- Property owner name(s) exactly as on the valuation notice
- Property address
- Valuation reference / assessment number (from the notice)
- Date of the valuation notice
- Date of this objection (must be within the state's deadline — see state doc;
  60 days from notice date is the common default, confirm per state)

**2. Statement of objection**
> I/We, [owner name(s)], being the registered owner(s) of the property at
> [property address], object to the [site value / capital improved value /
> unimproved value — use the term that state uses] of $[disputed value] as
> shown in the valuation notice dated [notice date], reference [ref number].

**3. Grounds for objection** (select applicable ground(s) — each state has its
own defined list of valid grounds, check the state doc; common grounds include):

- The valuation is too high having regard to comparable sales evidence (most
  common ground — see comps checklist)
- The valuation was based on incorrect property details (e.g. wrong land size,
  incorrect building area, zoning error, features that don't exist)
- The valuation methodology was incorrectly applied
- The valuation is not consistent with the value of comparable properties in
  the area as at the same valuation date

**4. Evidence summary**
> Based on the comparable sales evidence set out below (see attached comps
> table), I/we submit that the value of the property should be $[proposed
> value] as at [valuation date], not $[disputed value].

Insert the comps table here (from `comps_checklist.md` research) — property
address, sale date, sale price, land size, key differences from the subject
property, and the adjusted comparison.

**5. Supporting documents checklist (attach what's available)**
- [ ] Comparable sales evidence (from a source valid for that state, see comps
      checklist)
- [ ] Independent valuation report, if the client has commissioned one
- [ ] Photos showing property condition/features relevant to the dispute
- [ ] Evidence of incorrect property details (e.g. survey, floor plan) if that's
      a ground
- [ ] Any prior correspondence with the valuation authority

**6. Requested outcome**
> I/we request that the [site value / CIV / UV] be reduced to $[proposed value]
> based on the evidence provided, or an amount the [authority name] considers
> appropriate having regard to this evidence.

**7. Contact details & signature block**
- Owner's contact phone/email
- Signature and date (many states require a wet or digital signature matching
  their portal's identity verification — check state doc)
- If lodged by an agent on the owner's behalf: reference to the signed
  authorization and note that most portals require the owner to have granted
  agent access first (identity-verified step only the owner can complete)

## Customization notes per objection type

- **Land tax specific objections** (as opposed to a general rates valuation
  objection) may need to reference the specific land tax assessment notice
  rather than (or in addition to) the underlying land valuation, depending on
  the state's system — check whether land tax and general rates valuations
  are objected to via the same or separate processes in that state.
- Keep the tone factual and evidence-led — avoid subjective language ("this is
  unfair") in favour of comparable-sales-based argument, which is what
  reviewers actually weigh.
